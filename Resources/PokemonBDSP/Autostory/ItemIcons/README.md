# BDSP Bag item icons

Original BDSP Bag sprites downloaded from Bulbagarden Archives. Filenames use readable lowercase item names separated by hyphens, for example `escape-rope.png`.

`manifest.json` records item names, original source pages and image URLs, dimensions, and SHA-256 hashes. These game assets retain their original ownership; downloading them does not grant a new license. Validate their scaling against captured Bag screenshots before using them as matching templates.
